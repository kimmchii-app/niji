Profile 示範圖資料夾
====================

把每個 profile 代碼的示範圖放這裡，檔名 = 代碼，副檔名限 png。

單張：
  profile-images/5gl4zk5.png

多張（一個代碼多張，例如一男一女）：用連續編號
  profile-images/o54hkwn.png       ← 第 1 張
  profile-images/o54hkwn(1).png    ← 第 2 張
  profile-images/o54hkwn(2).png    ← 第 3 張
  ...

規則：
- 檔名 = profile 代碼，用純代碼（不要帶 --p / --profile），限 png。
- 多張要「連續」編號：base → (1) → (2)…；中間缺號會停在缺口之前。
- 顯示順序 = 編號順序（base、(1)、(2)…），你可用它控制男女先後。
- 相容 Windows 複製產生的空格版：o54hkwn (1).png 也讀得到。
- 在網頁選取某個 profile 後，這些圖會出現在右側「參考圖輪播」，可用上一張/下一張切換。
- 不用跑任何腳本，放檔即讀（找不到就自動略過，不會報錯）。
