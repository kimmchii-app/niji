# 🌈 Niji 提示詞配搭工具

niji 6 / niji 7 的中文題詞小幫手。只要點選中文標籤，就會自動組成英文提示詞，一鍵複製貼到 niji 生成圖片。

> 純前端（原生 HTML / CSS / JS，無框架），所有選擇會存在瀏覽器本機，關掉網頁再開也還在。透過 GitHub Pages 部署。

---

## 🚀 快速上手

只要選好中文標籤就可以請 niji 幫你生成照片！

**三步驟：**

1. **點選詞彙** — 從下方分類挑喜歡的（畫風、場景、髮型⋯⋯隨你混搭）
2. **按「📋 複製」** — 組好的英文提示詞一鍵入袋
3. **貼到 niji 上面就可以生成！**

**三個主頁籤：**

- ✨ **提示詞**：集中選擇畫面設定、人物與背景裝飾；人物可先選 👩 女性／👨 男性切換詞庫
- 🪪 **profile**：自行新增並可複選 Profile 代碼，選中的代碼會以 `--profile` 依序接在提示詞最後；也可切換 `--niji 6 / 7` 版本
- 🎭 **人設庫**：把角色外觀整組存檔，一鍵套用到不同場景

最終格式會是：

```
完整的背景與人物提示詞 --niji 版本 --p 代碼
```

（有選 niji 版本才會加 `--niji`；有選 profile 才會加 `--profile`）

## 🎨 人物設定

### 💇 髮型這樣玩

- 髮型類（長度／髮質／瀏海／造型／髮飾）都是**單選**，重選自動替換，不怕互相打架
- 選擇**髮型長度**時會跳出 🎨 **髮色視窗**；選擇髮質捲度、瀏海或造型則不會打斷操作。挑基本色 → 想要漸層或雙色？再挑一個第二色，工具會自動寫成 `pink to blue gradient hair` 這種漂亮句子！
- 想反悔？髮型抽屜底部的「🎨 髮色細節」按鈕隨時重開

### 👁 異色瞳這樣選

- 先在「眼睛」分類選擇**異色瞳**，接著於視窗分別挑第一色與第二色
- 工具會自動組成 `heterochromia eyes, one eye black, one eye gold` 這類完整提示詞
- 想換色時，可用眼睛抽屜底部的「👁 異色瞳細節」隨時重開

### 🐱 動物耳朵

- 「動物耳朵」分類點一下會跳出視窗，先選**種類**（貓／狗／狐／兔／狼／熊／虎／鼠耳，單選），再選**耳朵顏色**（可不選）
- 會自動組成 `white cat ears` 這種提示詞

### 👗 服裝分組挑選

- 服裝分成 👕 上衣／👖 下著／👗 連身服／🥼 外袍制服四個**收合小組**，點小組標題展開，其餘會自動收合
- 選擇襯衫、連身裙、毛衣、褲子等通用衣物時，會自動開啟 🎨 **顏色選單**；已選衣物可從服裝抽屜底部重新開啟

### 👓 配件與隨身道具

- 「配件」分類收錄領帶、眼鏡、墨鏡、護目鏡、拖鞋、項鍊、背包等；其中**領帶**一樣可換色
- 進入「隨身道具」按**手持某個物品**，就能從彈窗挑選，重選會自動替換

## 🎭 人設庫

- 在「提示詞」分頁選好角色後，切到 **人設庫** 分頁 → 輸入名稱 → 按 **➕ 儲存目前角色**
- 存下的內容：**性別、髮型、髮色（含第二色）、眼睛／異色瞳、動物耳朵**
- 點清單中的人設 = 套用；**只換這些角色設定，其餘（表情、動作、服裝、場景、背景⋯⋯）都會保留**
- 每筆可 ✏️ 改名、× 刪除

## ✨ 進階技巧

- 上方的彩色小膠囊點一下 ＝ 移除那個詞
- 提示詞中的彩色英文可以**點擊修改**；修改過的詞會在膠囊左側顯示 ✏️
- 按「➕ 新增自訂詞」可加入多個珊瑚橘色自訂詞；每個自訂詞都會顯示自己的標籤
- 你輸入過的自訂詞會自動存進「📚 記憶庫」；點開就能搜尋、分類、收藏★、置頂📌、改別名，一鍵把常用詞加回工作區
- 按住自訂框左側 ⠿ 拖曳把手，可把該詞移到任意逗號後方
- **畫面設定／背景裝飾**的預設詞也有 ⠿ 把手，可拖曳調整順序（人物語句維持自動排序）
- 🗑 清空一鍵重來；🌙／☀️ 切換深淺色
- 標題列的 📝 可查看**更新紀錄**；有沒看過的新紀錄時按鈕會亮紅點，點開就消失
- 你的選擇會自動記住，關掉網頁再開也還在！

## 🖼 Profile 示範圖

在「profile」分頁選取代碼後，右側會輪播對應的示範圖。

- 圖檔放在 `profile-images/`，檔名 = `代碼-n版本.png`（例如 `5gl4zk5-n7.png`、`5gl4zk5-n6.png`）
- 版本後綴跟著目前選的 niji 模式走（未選預設 n7）
- 一個代碼可放多張，用連續編號 `代碼-n7(1).png`、`代碼-n7(2).png`⋯⋯
- 詳細規則見 [profile-images/README.txt](profile-images/README.txt)

## 📁 專案結構

| 檔案 | 說明 |
|------|------|
| `index.html` | 頁面骨架與使用說明彈窗 |
| `css/style.css` | 樣式（深／淺色主題、性別主題色、RWD） |
| `js/prompts.js` | 提示詞詞庫（所有中文標籤 → 英文對應） |
| `js/config.js` | 性別與衣物顏色 |
| `js/profile-defaults.js` | 系統預設 Profile 代碼（niji6／niji7）與別名 |
| `js/changelog.js` | 更新紀錄內容（新的一筆加在陣列最上面即可） |
| `js/app.js` | 主程式（互動邏輯） |
| `profile-images/` | Profile 示範圖 |
